# FocusTrace Name and Brand Policy

The FocusTrace source code is licensed separately from the FocusTrace project name, logo and other brand identifiers.

The GNU General Public License applies to the covered source code. It does **not** grant permission to use the FocusTrace name or logo in a way that implies an unofficial fork, modified build, service or distribution is the official FocusTrace project.

This document is a project brand policy and does not claim that any FocusTrace mark is registered in every jurisdiction.

## Allowed uses

You may use the FocusTrace name truthfully to:

- refer to the official project;
- state that your software is compatible with FocusTrace;
- explain that your work is based on, derived from or interoperates with FocusTrace;
- link to the official repository;
- discuss, review or document the project.

For example, wording such as **“Based on FocusTrace”**, **“Compatible with FocusTrace”** or **“Fork of FocusTrace”** is generally appropriate when it is accurate and does not imply official status.

## Forks and modified distributions

If you distribute a materially modified version or independent fork, use a distinct product name and visual identity.

You may identify its origin in descriptive text, but the primary name, icon and store listing should make clear that the distribution is not the official FocusTrace release.

Do not reuse the official FocusTrace logo as the primary icon for a modified distribution without permission.

## No implied endorsement

Do not use the FocusTrace name, logo or project presentation in a way that suggests sponsorship, certification, endorsement or official maintenance when none exists.

## Community contributions

Normal references to FocusTrace in issues, pull requests, documentation, screenshots and community discussion are encouraged and do not require separate permission when they are accurate and non-misleading.

## Questions

If a use falls outside the examples above, contact the project maintainer before presenting it as official or using the project identity commercially.

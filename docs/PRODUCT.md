# FocusTrace product direction

FocusTrace is a local-first browser extension for accessibility debugging.

The product focuses on two complementary capabilities:

1. A WCAG-native rule engine for deterministic checks and review signals.
2. Runtime tracing for focus, SPA navigation, dialogs, keyboard interaction and DOM mutations.

The goal is not to replicate existing scanners. FocusTrace should explain what happened during an interaction, preserve evidence, and map findings to official accessibility guidance.
